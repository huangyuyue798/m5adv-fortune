# 玄机OS · M5ADV 玄机固件

> 仅发布编译好的固件二进制，**本仓库不包含任何源代码**。

把一台 M5Stack Cardputer ADV 变成口袋里的「离线玄学工具机」——七种传统占卜玩法全部内置、断网也能用，看不懂文言还能逐层翻译，想深入解读可选 AI（联网或手机本地跑，数据不外传）。

这不是一个演示 Demo，而是一台**开机即用、可日常把玩**的完整设备固件：图形化仪表盘界面、中文显示、按键交互、配网配置、省电续航、断电不丢时间，所有细节都做了打磨。

---

## 一、它解决什么问题

传统玄学工具要么是一堆一堆的网站/App（要联网、要授权、塞满广告），要么只有干巴巴的文字排布。这套固件想做的是：

- **完全离线可用**：所有算法和文本都在设备里，飞行模式、没网、出门在外都能起卦，不依赖任何服务器。
- **隐私可控**：不想联网就彻底不联；想要 AI 深入解读时，还可以让**手机浏览器本地跑模型**，问题不出手机。
- **看得懂**：每个卦象都有「文言原文 → 白话解读 → AI 深入解读」三层，从传统文化爱好者到完全不懂的人都能用。
- **拿得住**：针对电池供电做了省电优化，待机不空耗电；界面切换无闪烁，长时间把玩不累眼。

## 二、核心玩法（7 种，全部离线可用）

### 1. 黄历 · 择日
公历 / 农历 / 干支 / 生肖 / 宜忌 / 冲煞一屏呈现。`<>` 换日、`^v` 换周；按空格在「黄历」和「择日评分」间切换。择日按日干支五行与农历特殊日综合打分，**五档吉凶全可达**，辅助挑选吉日。

### 2. 六爻
三枚铜钱逐爻抛掷，带**翻转动画、正反面外观区分**（"背"和"字"一眼可分）。可摇动设备或按键起卦，投满六爻成卦，本卦 / 变卦 / 六亲神煞齐备，每次起卦用实时随机种子，同一时段多次起卦结果不再重复。

### 3. 求签
32 签，一签一世界。抽签带转签与竹签动画，给出签文与吉凶断语，仪式感拉满。

### 4. 梅花易数
报数起卦（上卦 / 下卦），生成卦象、互卦、变卦与体用生克。仪表盘卡片只放定长信息，按 OK 进入**整页解析**，长文绝不污染界面布局。

### 5. 小六壬
六宫掌诀环形仪表盘，掐指起课断局，带落宫动画。

### 6. 解梦
24 个梦象关键词搜索，支持**中文、全拼与首字母缩写**（如 `s` / `sh` / `fx`），逐字输入实时过滤，周公解梦风格断语。

### 7. 三层解读（贯穿所有卦象）
每个卦象都能逐层深入：

```
文言原文  ──OK──▶  白话解读  ──OK──▶  AI 深入解读
   ▲                  ▲                   ▲
   └────ESC 回退──────┴─────ESC 回退──────┘
```

`^v` 翻页看长文，总结前置、第一屏就看结论；文言层按 ESC 直接回卦象页。

## 三、AI 解读：三种模式任选

AI 是可选增强，**不开启也完全能用**。在主菜单第 7 项「配网」进入配网页（`192.168.4.1`）配置：

| 模式 | 说明 | 联网 | 适合谁 |
|------|------|------|--------|
| **关闭** | 仅用内置算法与文本，全程离线、零联网 | 否 | 只想离线占卜、注重隐私 |
| **云端 AI** | 填 API Key 联网解读，内置混元 / DeepSeek / OpenAI / 通义 / Kimi / 智谱预设，也支持自定义端点 | 是 | 想要最强解读、不介意联网 |
| **离线 AI（推荐）** | 设备显示二维码，手机扫码后在浏览器本地跑 WebLLM（Qwen2.5-0.5B），**免 Key、数据不出手机** | 仅对时用 WiFi | 想要 AI 但又不想上传数据 |

> 三种模式的 WiFi 都只在开机对时用一下，之后自动关闭射频；云端模式调用时按需重连，用完即关。

配网页同时还能设置：亮度、音量、日期时间、空闲省电、AI 服务商与模型。

## 四、续航与省电

针对电池供电做了完整优化：

- **对时后自动关 WiFi 射频**，用时按需重连，待机不再空耗电。
- **空闲 1 分钟自动熄屏至 3% 亮度**，任意按键瞬间唤醒。
- **CPU 降频试验（240→80MHz）**，可在设置里开关对比实测。
- 主菜单**三格电池图标**实时显示电量（0/33/66/80 分档亮格），主题色统一。

## 五、稳定性与易用性细节

- **界面无闪烁**：背景与上下块持久不重绘，只局部刷新变化区，切页一次上屏。
- **时间持久化**：无 RTC 电池也能断电保存时间（NTP + NVS 兜底），开机不回编译日期。
- **设置可持久化**：亮度 / 音量 / 日期时间 / 空闲省电均保存在设备里，音量默认 30%、亮度默认 50%。
- **中文显示**：内置中文字体，中文标题与断语直接显示。

## 六、完整操作说明

主菜单共 8 项：`黄历 / 六爻 / 求签 / 梅花 / 小六壬 / 解梦 / 配网 / 设置`。

| 按键 | 作用 |
|------|------|
| `;` `,` `.` `/`（fn 层方向键）或 `<` `>` `^` `v` | 方向选择 / 翻页 |
| `OK`（Enter） | 进入 / 确认 / 解读逐层深入 |
| `ESC`（fn + `` ` ``） | 返回 / 解读逐层回退 |
| 空格 | 黄历页切换择日评分 |
| 摇动设备 | 六爻起卦（等同 OK） |

> 解梦输入时，`; , . /` 是普通拼音字符输入，不再映射方向，避免打断 `s`/`sh`/`shui` 这类拼音。

## 十、常见问题

**Q：需要联网吗？**
不需要。所有占卜玩法、算法和文本都在设备里，完全离线可用。只有「开机对时」和「云端 AI」会用到网络，且对时后 WiFi 自动关闭。

**Q：AI 解读会把我的问题传出去吗？**
「关闭」和「离线 AI」模式不会——后者连模型都在你手机浏览器本地跑。「云端 AI」模式会把解读请求发给你选择的服务商，请用前了解其隐私政策。

**Q：能读到充电状态吗？**
这块板子的硬件读不到「是否正在充电」和充电电流，固件无法显示充电状态，属硬件限制。

**Q：断电后时间会重置吗？**
不会。时间保存在设备 NVS 中，开机恢复，不依赖 RTC 电池。
