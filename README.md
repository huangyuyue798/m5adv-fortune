# 玄机OS · M5ADV 玄机固件

> 仅发布编译好的固件二进制，**本仓库不包含任何源代码**。

运行在 M5Stack Cardputer ADV（ESP32-S3）上的图形化玄学工具集，深蓝星盘仪表盘风格。内置算法完全离线可用，支持手机配网与大模型 AI 解读（可选）。

## 功能特色

### 七大神算模块（内置算法，完全离线可用）
- **黄历**：公历/农历/干支/生肖/宜忌/冲煞一屏呈现，左右键翻日、空格切换择日评分
- **六爻**：三枚铜钱逐爻抛掷（翻转动画、正反面区分），本卦/变卦/六亲神煞齐备
- **求签**：32 签，转签与竹签动画，给出签文与吉凶断语
- **梅花易数**：报数起卦，体用生克，OK 进入整页解析
- **小六壬**：六宫掌诀环形仪表盘，掐指起课断局
- **解梦**：24 梦象关键词搜索（中文/拼音/首字母缩写），周公解梦风格
- **择日**：结合黄历宜忌与干支五行给出评分与等级

### 三层解读
文言原文 → 白话解读 → AI 深入解读。OK 逐层进入、ESC 逐级回退、^v 翻页。

### AI 三模式（配网页 `192.168.4.1` 配置）
- **关闭**：仅用内置算法，全程离线、零联网
- **云端 AI**：填 API Key 联网解读，内置混元/DeepSeek/OpenAI/通义/Kimi/智谱预设
- **离线 AI（推荐）**：设备出二维码，手机浏览器本地跑 WebLLM（Qwen2.5-0.5B），免 Key、数据不出手机

### 省电与续航
- 对时后自动关闭 WiFi 射频，用时按需重连
- 空闲 1 分钟熄屏至 3% 亮度，任意按键唤醒
- CPU 降频可开关（240→80MHz）
- 主菜单三格电池图标，主题色统一

### 稳定与易用
- 界面无闪烁（持久框架 + 局部重绘）
- 时间持久化（NTP + NVS 兜底，断电不重置）
- 亮度/音量/日期时间/空闲省电均可设置并持久化

## 硬件要求

M5Stack **Cardputer ADV**（ESP32-S3FN8，8MB Flash，240×135 屏）。

## 烧录方法

### 方式一：M5Burner（推荐）
在 M5Burner 中搜索固件「玄机OS」，选择适配设备 Cardputer ADV 直接烧录。

### 方式二：esptool
下载本仓库 Releases 中的 `m5adv-fortune-v56.bin`（完整合并镜像），执行：

```
esptool.py --chip esp32s3 --port <串口> --baud 921600 write_flash 0x0 m5adv-fortune-v56.bin
```

### 方式三：AI Agent（最简单）
下载本仓库 Releases 中的 `m5adv-fortune-v56.bin`（完整合并镜像）
发给AI：将这个固件烧录到m5adv中

## 操作

方向键（`fn` 层 `; , . /`）选择，OK 进入，ESC 返回。解读页 `^v` 翻页、OK 逐层深入、ESC 逐级回退。
